## 🌟 核心功能

- **多维度检索**：支持按项目名称、负责人、依托单位、学科代码（申请代码）、项目类型（面上/青年/重点/杰青/优青）联合筛选。
- **高校与科研院所资助榜单**：统计各年度高校中标项数与经费总额分布。
- **学科前沿风向标**：快速掌握近年国自然重点倾斜的研究领域与交叉学科热点。
