## 🌟 核心功能与科研辅助

1. **国家自然科学基金全量多维检索**：
   - 支持按**项目名称**、**项目负责人**、**依托高校/科研院所**精准定位；
   - 支持按**学部与申请代码（一级代码/二级代码）**进行学科下钻筛选；
   - 支持按**项目类别**（面上项目、青年科学基金项目、重点项目、国家杰出青年科学基金、优秀青年科学基金、重大项目等）分流检索。
2. **立项趋势与经费大数据**：
   - 掌握近十年特定学科方向的获批项数与平均资助强度；
   - 辅助国家基金申报人精准把握国家重点资助导向与选题脉络。
3. **高校与科研院所科研竞争力排行榜**：
   - 各依托单位年度总中标项数、总资助金额与各学部学科分布一目了然。
